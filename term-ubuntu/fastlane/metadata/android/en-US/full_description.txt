ThothTerm Resolute runs a genuine Ubuntu 26.04 LTS (ARM64) userland on your phone
and gives you a proper terminal into it. No root, no VM, no remote server.

It is a terminal first. The Ubuntu side is real Ubuntu: apt works, dpkg works,
sudo is the distribution's own sudo rather than a wrapper, and anything you
install stays installed. Your home directory and everything in it survive app
updates.

Features

* Ubuntu 26.04 LTS ARM64, downloaded with your consent and set up on first launch
* Real sudo and a working apt/dpkg package manager
* Persistent home directory and root filesystem across app upgrades
* Multiple terminal sessions with a window list
* Pinch-to-zoom, plus Zoom in / Zoom out / Reset font size
* An extra keys row for Esc, Ctrl, Alt, Tab and arrows
* Portrait and landscape, with the layout adapting to each
* Copy and paste, text selection and scrollback
* Tools you install under your home directory stay on PATH between sessions
* LAN Mode: open this Ubuntu in a web browser on another computer on the
  same Wi-Fi, each browser with a terminal of its own

LAN Mode

LAN Mode is off by default and listens only while you have it on. It is in
the menu, above Windows. When it is on, the app shows an address to open in
a browser on the same Wi-Fi or Ethernet network and a short one-time PIN.
The browser must pair with that PIN before it gets anything. Each browser
gets its own terminal; the windows on your phone are never shared. It never
listens on mobile data or the Internet, and turning it off disconnects
every browser and invalidates their access. The connection is plain HTTP:
traffic on your network is not encrypted, so use it only on networks you
trust.

First run

This build does not include the Ubuntu userland. The first launch explains
what will be downloaded and downloads nothing unless you agree. Then:

1. The Ubuntu 26.04 base system (about 33 MB) is downloaded from Canonical's
   cdimage.ubuntu.com and checked against a SHA-256 built into the app; it is
   refused if it does not match.
2. Right after, in the background, the app installs Ubuntu's own sudo with
   apt from Ubuntu's package archive (archive.ubuntu.com and
   security.ubuntu.com): the package lists and sudo, about 30 MB, verified by
   apt against Ubuntu's archive signing keys. The terminal opens without
   waiting for this; if it fails, the terminal still works and the menu
   offers to retry it.

Later, the app contacts the package archive only when sudo is missing (a
setup that failed, or you removed it). Any other download is apt run by you.

Requirements

* A 64-bit ARM device (arm64-v8a). Other ABIs are not supported.
* About 1.5 GB of free space for the Ubuntu environment.

This is an early release. It concentrates on being a solid, honest terminal and
a correct Ubuntu environment; more features are planned for later updates.
