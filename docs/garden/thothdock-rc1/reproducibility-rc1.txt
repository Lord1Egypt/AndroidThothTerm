  1. Local WSL2 (Ubuntu), JDK 21, Go 1.26.8 (go.dev toolchain), NDK from the SDK, umask 022
  2. GitHub Actions run 37294262778 (ubuntu-24.04, Temurin 21, setup-go 1.26.8)
  3. The F-Droid CI job in registry.gitlab.com/fdroid/fdroidserver:buildserver-trixie
     (fdroid build --test --refresh-scanner --on-server; Go 1.26.8 built from source with
     make.bash, bootstrapped by Go 1.24.6 built from source; build user umask 002)

  size 15985055 bytes, 985 entries

What had to be fixed to get there (each found by comparing the F-Droid job's APK with ours):
  - AGP stamped the git revision (or NO_VALID_GIT_FOUND) into META-INF/version-control-info.textproto:
    vcsInfo.include = false for the release build type.
  - The Engine Guard .deb placeholders were gzip-compressed (the buildserver's gzip made a data.tar.gz
    one byte different): now built uncompressed (dpkg-deb -Znone).
  - The same packages carried the build user's umask in directory modes (drwxrwxr-x under 002):
    engine-guard/build.sh sets umask 022, and ThothDock CI diffs builds under 022 and 002.

Scope: this is the unsigned release APK. Debug builds are not reproducible (AGP orders classesN.dex
differently from run to run), which is why the Golden QA APK was not bit-identical between builds.
A signed APK matches a rebuild only after the signature is compared apart from the signing block.
Earlier comparison runs (same-path rebuilds, clone at another path) are summarised in the git history.
