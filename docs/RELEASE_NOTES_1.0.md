# ThothTerm Terminal Emulator 1.0.0 — Release Notes

ThothTerm 1.0.0 is the first stable release of the standalone Android terminal
emulator.

## Highlights

- A modern Android terminal emulator with a clean, focused interface.
- Multiple terminal windows: open, switch, and close sessions; sessions stay
  alive in the background while the app is minimized.
- Extra Keys toolbar with NAV and SYM pages, including ESC, CTRL, ALT, TAB,
  HOME, END, arrows, Page Up/Down, Insert/Delete, and common shell symbols. All
  keys fit on screen without horizontal scrolling.
- CTRL and ALT support one-shot and locked modes, with clear `[1]` and `[L]`
  state labels.
- Terminal themes for Dark, Light, System, and AMOLED, plus independent
  terminal color schemes.
- Full UTF-8 support.
- Arabic and RTL text rendering, including mixed Arabic, English, and numeric
  lines, with correct cursor and selection behavior.
- Improved terminal cursor alignment so text and cursor no longer drift apart.
- Keyboard and session improvements: software-keyboard coexistence, clearer
  Back-button behavior, and reorganized, easier-to-find Settings.
- Fresh ThothTerm app icon (adaptive, legacy, round, and themed monochrome).

## Compatibility

- Android 4.1 (API 16) and newer.
- Architectures: arm64-v8a, armeabi-v7a, x86, x86_64.

## Notes

- This app is a terminal emulator for Android. It does not include a Linux
  distribution.
- Upstream attribution and licenses are preserved in the app's `NOTICE` and
  source headers.
