ThothTerm Ubuntu runs a genuine Ubuntu 26.04 LTS (ARM64) userland on your phone
and gives you a proper terminal into it. No root, no VM, no remote server.

It is a terminal first. The Ubuntu side is real Ubuntu: apt works, dpkg works,
sudo is the distribution's own sudo rather than a wrapper, and anything you
install stays installed. Your home directory and everything in it survive app
updates.

Features

* Ubuntu 26.04 LTS ARM64, embedded and set up on first launch
* Real sudo and a working apt/dpkg package manager
* Persistent home directory and root filesystem across app upgrades
* Multiple terminal sessions with a window list
* Pinch-to-zoom, plus Zoom in / Zoom out / Reset font size
* An extra keys row for Esc, Ctrl, Alt, Tab and arrows
* Portrait and landscape, with the layout adapting to each
* Copy and paste, text selection and scrollback
* Tools you install under your home directory stay on PATH between sessions

First run

The F-Droid build does not include the Ubuntu userland, so the first launch
offers to download it (about 33 MB) from Canonical's cdimage.ubuntu.com. The
app explains this before doing anything and downloads nothing unless you
agree. The archive is checked against a SHA-256 built into the app and is
refused if it does not match.

Requirements

* A 64-bit ARM device (arm64-v8a). Other ABIs are not supported.
* Roughly 400 MB of free space for the Ubuntu environment.

This is an early release. It concentrates on being a solid, honest terminal and
a correct Ubuntu environment; more features are planned for later updates.
