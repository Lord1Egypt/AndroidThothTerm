First public release.

* Ubuntu 26.04 LTS ARM64 userland, prepared on first launch
* Genuine Ubuntu sudo, apt and dpkg
* Persistent home directory and root filesystem across upgrades
* Pinch-to-zoom and font size menu actions
* Ongoing notification while a terminal session is running
* Tools installed under your home directory stay on PATH between sessions

On F-Droid the Ubuntu userland is not part of the app package. The first
launch explains what will be downloaded and from where, and fetches it only
if you agree; the download is checked against a SHA-256 fixed in the app's
source before it is used.
